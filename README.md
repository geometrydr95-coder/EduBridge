# EduBridge

## Premium Student Skill Exchange Platform

EduBridge is a modern Android application designed to connect university students through skill sharing, tutoring, collaboration, mentorship, and peer-to-peer learning.

The platform enables students to:

* Exchange skills
* Offer tutoring services
* Learn from other students
* Collaborate on projects
* Monetize talents
* Trade skills through barter or payment systems

EduBridge is inspired by the energy of African innovation ecosystems and combines the experience of platforms like LinkedIn, Fiverr, and student collaboration hubs into one mobile-first ecosystem.

---

# Vision

EduBridge aims to bridge opportunity gaps among university students by creating a trusted digital ecosystem where students can:

* Learn practical skills
* Build professional networks
* Access peer mentorship
* Discover campus talent
* Grow portfolios
* Create income opportunities

The platform is optimized for students in Kenya and other emerging digital economies where affordable, peer-driven learning systems are highly impactful.

# Installation

## Clone the Repository

```bash
git clone https://github.com/geometrydr95-coder/EduBridge.git
```

## Open Project

Open the project using:

* Android Studio Hedgehog or newer

## Add Firebase Configuration

Place your:

```plaintext
google-services.json
```

inside:

```plaintext
app/
```

## Build the Project

```bash
./gradlew build
```
